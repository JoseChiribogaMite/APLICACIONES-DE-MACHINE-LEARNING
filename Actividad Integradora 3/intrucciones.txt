ML CLASIFICACIÓN: IA EXPLICATIVA y Búsqueda de mejores hiperparámetros.


Objetivo
Desarrollar en Python un modelo de ML para clasificación que incluya el análisis exploratorio de datos (EDA) automatizado, preprocesamiento, búsqueda de hiperparámetros (grid/randomized/bayesian) y la evaluación e interpretación de modelos de aprendizaje automático mediante técnicas de Inteligencia Artificial Explicativa (XAI).

El objetivo principal es entrenar un modelo predictivo optimizado y "abrir la caja negra" aplicando Feature Importance, Permutation Importance y SHAP Values para interpretar sus decisiones a nivel global y local.



El estudiante es libre de usar un dataset a su conveniencia, en el área de interés que más le apetezca. Se recomienda que el estudiante use un dataset no usado en clases previas (titanic/iris). Kaggle y UCI son sitios web que proveen algunos datasets para practicar.

https://www.kaggle.com/datasets

https://archive.ics.uci.edu/datasets
